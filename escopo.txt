Escopo do Projeto

Objetivo Geral: Desenvolver um SaaS simples usando a WhatsApp Cloud API para coletar nome do usuário, confirmar termos de uso, salvar dados no MongoDB Atlas, e responder a interações com links fixos (Etapa 1) ou respostas de IA baseadas em leitura dinâmica de sites/PDFs (Etapa 2-B), mantendo compliance com políticas do WhatsApp e custos zero.

Funcionalidades-Chave:

· Coleta e confirmação de nome com loop até validação.
· Confirmação explícita de termos de uso (opt-in) para mensagens futuras.
· Menu de opções (Tópico A, Tópico B, Falar com Atendente).
· Etapa 1: Envio de link fixo com base na opção escolhida.
· Etapa 2-B: Solicitação de dúvida, integração com IA (Hugging Face) e resposta com leitura dinâmica de sites/PDFs via Firecrawl e pdf-parse.
· Salvamento de dados (nome, número) e URLs de contexto no MongoDB Atlas.
· Gerenciamento de URLs via interface web nativa do MongoDB Atlas (visualização, edição e deleção).
· Compliance: Mensagem clara de consentimento e opção "STOP" para cancelar.

Restrições:

· Custos zero: Usar tiers gratuitos (WhatsApp Cloud API, MongoDB Atlas, Render.com, Hugging Face, Firecrawl free tier).
· Conformidade com políticas do WhatsApp (opt-in explícito, templates para mensagens proativas).
· Mudanças mínimas no código existente (app.js), preservando estrutura e nomes.
· Estados em memória (conversationStates) por simplicidade; migração para DB só se escalar.

Dependências:

· Conta no Meta Business Manager (business.facebook.com).
· Número de telefone dedicado (SMS para verificação).
· Servidor no Render.com (free tier, 750h/mês).
· MongoDB Atlas (free tier, 512MB) com interface web nativa para gerenciamento.
· Hugging Face API token (free, huggingface.co).
· Firecrawl API key (free tier, 500 páginas/mês, firecrawl.dev).
· Dependências Node.js: express, axios, dotenv, mongoose.

Etapa 1: Implementada com sucesso

Fluxo: Coleta nome, confirmação, termos, menu com links fixos.
Código app.js atualizado com webhook, estados em memória, salvamento no MongoDB.
Deploy no Render.com (URL: https://bot-whatsapp-oy4p.onrender.com).
Testes manuais via Postman e WhatsApp OK, com salvamento de dados.

Etapa 2-B: Mantida como está (pendente)

Solicitação de dúvida, integração com IA (Hugging Face) e resposta com leitura dinâmica de sites/PDFs via Firecrawl e pdf-parse.
